# Notas Rápidas & Tablón

## Bienvenida a TBH
Este panel se actualiza automáticamente en la televisión cada vez que guardás un cambio en cualquiera de estos archivos Markdown desde Obsidian.

## Modos de Uso
- **En la TV:** Usar el botón de pantalla completa o presionar F11 en el navegador. La vista está optimizada con fuentes grandes y alto contraste.
- **En el Celular:** Abrir la misma URL (`http://192.168.0.200:3001`) para alternar a "Modo Control", pausar/reiniciar timers y revisar las listas cómodamente.
