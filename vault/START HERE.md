# Start here — your FREE starter vault

This is the single practice workspace for the free course and Premium lab. Open this folder as a vault; do not create a separate scratch vault for the first two lessons.

1. Open Home.md and Client Website.
2. Find Client Website.md outside Obsidian to see the normal file.
3. Inspect Properties and open Business Context from its link.
4. Enable the Templates core plugin and set the template folder to `00 Human/80 Templates`.
5. Create a note in `00 Human/10 Daily Notes`, name it with today's YYYY-MM-DD date and insert Daily Driver through the Templates command.
6. Add a link to that note from Home.
7. Open this exact vault folder in your file-capable agent and prove it can read Client Website before requesting a draft.
8. Run the supplied Client Update workflow and inspect its output and activity entry.

The fictional Example Day is a demonstration, not today's actual state. Keep your real measurements separate from it.

## Practice projects

Client Website is the only active supplied project and has two open tasks. Completed Example is complete and contains a deliberate unchecked leftover. The Premium lab learns to exclude that leftover and tasks in templates or examples.

If you add your own active projects, expect the counts to change. Fixed expected counts apply only to unchanged supplied examples.

## Data and ownership

Human holds approved source/context. Machine holds generated work and workflow material. System explains the map. No outside account, paid plugin or HQ app is required to use this starter manually.

Before using important real work, make a recoverable backup outside this folder. The course does not configure a sync or backup service.
