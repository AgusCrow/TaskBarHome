# Workflow

1. Read the named project and context sources.
2. Identify recorded completed work, open decisions and next actions.
3. Draft Completed, Waiting On and Next sections using the example format.
4. Save a dated Markdown file in output/, using a distinct version if needed.
5. Read back the result and compare it with the sources.
6. Append the actual result and output path to the activity log.
7. Suggest a useful finding for the user to review.
